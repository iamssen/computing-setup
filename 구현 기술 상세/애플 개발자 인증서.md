# macOS 권한 유지를 위한 인증서 서명

- iCloud 폴더 접근같이 macOS 보안 권한은 `node`, `*.app` 같은 App을 대상으로 부여됨
- App 업데이트 시, 동일한 서명이 부여되어 있어야만 같은 App으로 인식하고 보안 권한을 유지할 수 있음

# 다른 Mac 기기로 전송

- **키체인 접근 → 로그인 → 내 인증서**를 열고, `Apple Development` 인증서를 펼쳐 개인 키가 연결되어 있는지 확인.
- 인증서 행을 선택하고 **파일 → 항목 내보내기**에서 `.p12` 형식으로 저장. 
  - 인증서와 개인 키가 함께 포함되므로 따로 전송할 필요가 없음.
- 새 Mac에서 `.p12`를 더블 클릭하고, 내보낼 때 설정한 파일 암호를 입력하여 **로그인 키체인**으로 가져온다.
- **키체인 접근 → 내 인증서**에서 인증서를 펼쳐 개인 키가 함께 표시되는지 확인.
- `certificate is not trusted`가 표시되면 발급자가 WWDR G3인지 확인. 해당 중간 인증서가 없다면 [Apple 공식 WWDR G3 인증서](https://www.apple.com/certificateauthority/AppleWWDRCAG3.cer)를 내려받아 새 Mac의 **시스템 키체인**에 설치하고 다시 확인. 개발자 인증서의 신뢰 설정은 **시스템 기본값 사용**으로 둔다. ([Apple 안내](https://help.apple.com/xcode/mac/current/en.lproj/devc4c7101d8.html))

# 앱 빌드 시 인증서 사용

## 인증서 지문 조회·설정

조회된 인증서의 40자리 SHA-1 지문을 `~/.config/fish/config.fish`에 설정. 인증서 교체 시 새 지문으로 변경.

```fish
security find-identity -v -p codesigning

# config.fish
set -x SIGNING_IDENTITY "선택한 인증서의 SHA-1 지문"
```

## 검증 후 앱 서명

컴파일 전에 검증하고, 빌드 후 지정한 인증서로 서명. 실패 시 중단.

```fish
#!/usr/bin/env fish

set -l app_path "/path/to/MyApp.app"

validate-signing-identity "$SIGNING_IDENTITY"
or exit 1

# 이 위치에서 앱 빌드 명령 실행

# 앱 빌드 후 서명
codesign --force --sign "$SIGNING_IDENTITY" "$app_path"
or exit 1

# 서명 무결성 확인
codesign --verify --strict "$app_path"
or exit 1
```
